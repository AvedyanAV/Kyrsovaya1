# Программа для обработки банковских операции| Домашняя работа Skypro
## 


## Функционал
- Программа может считывать финансовые операции с xlsx файла
- В программу добавлен функционал вывода курса валют согласно настроек
- В программу добавлен функционал вывода курса акции согласно настроек
- Программа может подсчитать траты по заданному диапазону дат
- Программа может искать финансовые операции по имени человека которому был напрвлен перевод
- Программа выводит данные по каждой карте пользователя и по операциям
